# Sirius Wiki

Небольшая студенческая вики с записями лекций

## Структура

```text
sirius-wiki/
├─ life/
│  ├─ campus.md
│  └─ services.md
└─ articles/
   ├─ 2026-09-01/
   │  └─ welcome.md
   └─ 2026-09-02/
      └─ markdown-example.md
```

`life/` — постоянные статьи про жизнь в университете.
`articles/YYYY-MM-DD/` — учебные статьи, сгруппированные по дням.

## Как добавить статью

Создай `.md` файл в `life/` или в папке нужного дня внутри `articles/` и отправь изменения в GitHub.

В начале файла можно указать:

```md
---
title: Название статьи
description: Короткое описание
subject: История
order: 1
---
```

Поле `subject` используется для режима **«По предметам»** в разделе «Учёба». Если его не указать, статья попадёт в предмет **«Другое»**. Дата папки `articles/YYYY-MM-DD/` по-прежнему используется для режима **«По дням»**.

## Формулы LaTeX

Статьи поддерживают формулы LaTeX, которые отображаются с помощью KaTeX. Для формул внутри строки используй одиночные знаки доллара:

```md
Площадь круга: $A = \pi r^2$.
```

Для отдельной формулы по центру используй двойные знаки доллара:

```md
$$
e^{i\pi} + 1 = 0
$$
```

## Скачивание файлов

Добавь блок для скачивания рукописного конспекта в статью с помощью такого синтаксиса:

```md
:::download
title: Скачать рукописный конспект
file: articles/files/linal1.pdf
description: Конспект лекций по линейной алгебре.
:::
```

Путь в поле `file` указывается относительно корня проекта. Поля `title` и `description` необязательны.

## Тема, расписание и установка

Переключатель темы поддерживает светлую, чёрную и системную тему. Выбор сохраняется.
На странице «Расписание» доступны ИОП-ИТ-26/1 и ИОП-ИТ-26/2, выбор дня,
аудитории, преподаватели и отсчёт до следующей пары. Время всегда московское.

Кнопка «Установить приложение» вызывает установку PWA в поддерживающих браузерах
или показывает инструкцию. Требуется HTTPS (для разработки подходит localhost).
После первого успешного открытия и надписи «Готово к работе без интернета» доступны
оболочка, тексты статей с формулами и последнее расписание. Примерный объём — 2 МБ.
PDF, внешние картинки и ссылки автоматически не сохраняются. Браузер может очистить
данные при нехватке места. Для новой версии закройте все окна приложения и откройте снова.

### Автоматическое расписание

`python3 scripts/update-schedule.py` читает публичный Livewire-интерфейс
https://schedule.siriusuniversity.ru. Сохраняются текущая и две следующие недели.
При ошибке или неожиданном формате предыдущий `data/schedule.json` не перезаписывается.
Одновременные занятия подгрупп сохраняются отдельно. Названия и аудитории берутся из источника.

Workflow `.github/workflows/pages.yml` обновляет расписание при публикации и примерно
раз в час. Это начнёт работать после отправки изменений в основную ветку и при включённых
GitHub Actions / Pages (источник публикации — GitHub Actions). Планировщик GitHub может
задерживать запуск; время фактического обновления отображается в приложении. После
длительной неактивности репозитория GitHub может отключить запуски по расписанию.
Приложение проверяет опубликованный снимок каждые 15 минут, при открытии, возвращении
во вкладку и восстановлении сети. Кнопка обновления получает последнюю опубликованную
версию, а не запускает загрузку университета напрямую. О недоступности источника сообщает
workflow; устаревшая версия видна по исходному времени обновления.

### Напоминания

Можно выбрать 5, 10, 15 или 30 минут до начала. Разрешение браузера запрашивается
по кнопке. Уведомления относятся к выбранной группе; одновременные занятия объединяются.
Снимок старше суток не вызывает уведомлений. Таймер работает только пока приложение
открыто; в фоне браузер может его приостановить. Сервер Push не подключён.

«Добавить в календарь» скачивает ICS с сигналами для сохранённых занятий.
Календарь может напоминать при закрытой PWA и без сети, если разрешены его уведомления.
Импорт не является подпиской: после изменения расписания обновите импорт; поведение
дубликатов и сигналов зависит от календаря. На iPhone веб-уведомления могут требовать
установки приложения на экран Домой.

### Проверка

```sh
node --test tests/*.test.cjs
python3 -m unittest discover -s tests
node scripts/version-worker.mjs
python3 -m http.server 8765
```

Скрипт версионирования создаёт новый ключ офлайн-кэша при изменениях оболочки или ресурсов.
KaTeX 0.16.22 хранится в `vendor/katex` с лицензией MIT для работы формул без CDN.
