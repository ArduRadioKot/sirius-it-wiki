# Архив черновиков

Материалы из этой папки были опубликованы в разделе «Учёба».

Если дата занятия подтверждена источником, статья лежит в `articles/YYYY-MM-DD/`.
Если дату надёжно установить не удалось из-за недоступности расписания, статья опубликована в `articles/undated/` и в интерфейсе показывается как **«Без подтверждённой даты»**.

После получения точного расписания ИОП-ИТ26-1 статьи из `articles/undated/` можно перенести в соответствующие папки дат и заново выполнить `node generate-index.mjs`.
