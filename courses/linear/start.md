## Как готовиться

В учебнике шесть глав. В каждой есть объяснение, схема, задача с раскрывающимся решением и самопроверка. В последней главе **17 билетов в порядке списка**. У каждого есть рисунок, письменный ответ и два дополнительных разбора с решениями.

## Как проходит коллоквиум

По приложенному списку на письменную подготовку отводят **30–40 минут**. Первый вопрос билета проверяет определение или формулировку (15 баллов), второй — формулировку с доказательством (55 баллов). На устной части могут уточнить письменные ответы и задать два дополнительных вопроса по всему курсу (по 15 баллов).

Потренируйся восстанавливать доказательство по схеме. Для каждого билета запиши условия, вывод и обоснование каждого ключевого шага. Для движений держи под рукой контрпримеры: проекция на ось склеивает точки, растяжение меняет длину, отражение меняет ориентацию.
