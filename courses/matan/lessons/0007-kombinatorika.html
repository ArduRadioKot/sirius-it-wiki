Разминка

1. Правила сложения и умножения

Правило умножения. Если в множестве A₁ содержится n₁ элементов, в A₂ — n₂ элементов, …, в Aₖ — nₖ элементов, то число способов одновременно выбрать по одному элементу из A₁, A₂, …, Aₖ в указанном порядке равно n₁ · n₂ · … · nₖ. Пратусевич, с. 39

Правило сложения. Если множества A₁, …, Aₖ не имеют общих элементов, то количество элементов в их объединении равно сумме количеств элементов в каждом из множеств. с. 40

Пояснение

Выбираем одно и другое — умножаем. Выбираем одно или другое (варианты не пересекаются) — складываем. 30 карандашей и 40 ручек: «ручку и карандаш» — 30 · 40 = 1200; «ручку или карандаш» — 30 + 40 = 70.

Определение. Число Aₙᵏ = n · (n − 1) · … · (n − k + 1) называется числом размещений из n предметов по k. Количество способов переставить n различных предметов называется числом перестановок: Pₙ = n! = Aₙⁿ. с. 42

Определение. Число способов выбрать k предметов из n без учёта порядка называется числом сочетаний из n по k: Cₙᵏ = n!/(k!(n − k)!). с. 44

Пояснение

Сочетания получаются из размещений: каждую команду из k человек можно выстроить в очередь k! способами, поэтому Cₙᵏ = Aₙᵏ / k!. Пример: 3 человека из 7 в очередь — 7 · 6 · 5 = 210, команд — 210/6 = 35.

Наборы шаров. Число способов выбрать k шаров из шаров n цветов (шаров каждого цвета сколько угодно) равно Cₙ₊ₖ₋₁ᵏ. Дехтярь и др., §2.2

Запишем набор как строку из k шаров «●» и n − 1 перегородок «|» между цветами. Например, 2 красных и 1 синий из 2 цветов: «●●|●». Всего n + k − 1 мест, из них нужно выбрать k мест под шары.

3. Бином Ньютона

(a + b)ⁿ = Cₙ⁰aⁿ + Cₙ¹aⁿ⁻¹b + … + Cₙᵏaⁿ⁻ᵏbᵏ + … + Cₙⁿbⁿ с. 45

Пояснение

Раскрываем n скобок (a + b)(a + b)…(a + b). Слагаемое aⁿ⁻ᵏbᵏ получается, когда из k скобок взяли b, а из остальных — a. Выбрать эти k скобок можно Cₙᵏ способами. Пример: (a + b)² = a² + 2ab + b², и C₂¹ = 2.

Свойства биномиальных коэффициентов. с. 45–47

  1. Симметричность: Cₙᵏ = Cₙⁿ⁻ᵏ.
  2. Рекуррентное соотношение: Cₙᵏ + Cₙᵏ⁻¹ = Cₙ₊₁ᵏ.
  3. Сумма: Cₙ⁰ + Cₙ¹ + … + Cₙⁿ = 2ⁿ.
Пояснение: комбинаторные доказательства
  1. Выбрать k человек из n, которые пойдут, — то же, что выбрать n − k, которые останутся.
  2. Выбираем k человек из n + 1, среди которых Петя. Если Петя вошёл, остальных k − 1 выбираем из n: Cₙᵏ⁻¹. Если не вошёл, выбираем k из n: Cₙᵏ. По правилу сложения всего Cₙᵏ + Cₙᵏ⁻¹.
  3. Подставим a = b = 1 в бином. Или: обе части — число всех подмножеств множества из n элементов.

4. Формула включений-исключений

|A ∪ B| = |A| + |B| − |A ∩ B|

|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C| Дехтярь и др., теорема 15

Пояснение

Складывая |A| и |B|, общие элементы мы посчитали дважды — один раз вычитаем. Пример: от 1 до 100 на 2 делятся 50 чисел, на 3 — 33, на 6 (и на 2, и на 3) — 16. На 2 или на 3: 50 + 33 − 16 = 67.

Элементы комбинаторики

Правило сложения. «Если множества A₁, …, Aₖ не имеют общих элементов, то количество элементов в их объединении равно сумме количеств элементов в каждом из множеств»

Правило умножения. «Если в множестве A₁ содержится n₁ элементов, в A₂ — n₂ элементов, …, в Aₖ — nₖ элементов, то число способов одновременно выбрать один элемент множества A₁, один элемент множества A₂, …, один элемент множества Aₖ в указанном порядке равно n₁ · n₂ · … · nₖ»

Примеры:

  1. 30 карандашей и 40 ручек: выбрать ручку и карандаш — 30 · 40 = 1200 способов, т.к. правило умножения.
  2. Выбрать ручку или карандаш — 30 + 40 = 70 способов, т.к. правило сложения.

Четыре вида размещений

Выбираем k предметов из n. Вопросы: важен ли порядок? можно ли повторять?

Опр. 1 «Упорядоченные размещения с повторениями (слова длины k в алфавите из n букв): их число равно nᵏ»

Примеры:

  1. Слова длины 3 из букв {а, б}: 2³ = 8, т.к. на каждое из 3 мест — 2 варианта.

Опр. 2 «Число Aₙᵏ = n · (n − 1) · … · (n − k + 1) называется числом размещений из n предметов по k (упорядоченные размещения без повторений, «очереди»)»

Обозначение: Aₙᵏ = n!/(n − k)! (читается «а из эн по ка»)

Примеры:

  1. Директор и заместитель из 10 сотрудников: A₁₀² = 10 · 9 = 90, т.к. порядок важен.

Опр. 3 «Количество способов переставить n различных предметов называется числом перестановок»

Обозначение: Pₙ = n! = Aₙⁿ

Примеры:

  1. 5 человек в ряд: 5! = 120.

Опр. 4 «Число Cₙᵏ = n!/(k!(n − k)!) — число способов выбрать k предметов из n без учёта порядка — называется числом сочетаний из n по k (неупорядоченные размещения без повторений, «команды»)»

Обозначение: Cₙᵏ (читается «цэ из эн по ка»)

Примеры:

  1. Команда из 3 человек из 7: C₇³ = 7 · 6 · 5/3! = 35, т.к. порядок не важен.

Опр. 5 «Неупорядоченные размещения с повторениями («наборы разноцветных шаров»): число способов выбрать k шаров из шаров n цветов равно Cₙ₊ₖ₋₁ᵏ»

Примеры:

  1. 3 шара из шаров 2 цветов: C₄³ = 4 (ККК, ККС, КСС, ССС).

Доказательство: набор кодируем строкой из k шаров и n − 1 перегородок между цветами; всего n + k − 1 мест, выбираем места для шаров: Cₙ₊ₖ₋₁ᵏ.

порядок важен → A или nᵏ; не важен → C. Повторы можно → nᵏ или Cₙ₊ₖ₋₁ᵏ.

Бином Ньютона

Т. (бином Ньютона) «(a + b)ⁿ = Cₙ⁰aⁿ + Cₙ¹aⁿ⁻¹b + … + Cₙᵏaⁿ⁻ᵏbᵏ + … + Cₙⁿbⁿ»

Доказательство: раскрываем скобки в (a + b) · … · (a + b): слагаемое aⁿ⁻ᵏbᵏ получается, когда из k скобок берём b, из остальных — a. Способов выбрать эти k скобок — Cₙᵏ.

Т. (свойства биномиальных коэффициентов) «1) Cₙᵏ = Cₙⁿ⁻ᵏ — симметричность; 2) Cₙᵏ + Cₙᵏ⁻¹ = Cₙ₊₁ᵏ — рекуррентное соотношение; 3) Cₙ⁰ + Cₙ¹ + … + Cₙⁿ = 2ⁿ»

Доказательство:

  1. Выбрать k человек из n — то же, что выбрать n − k, которых не берём.
  2. Выбираем k из n + 1 человек, среди них Петя. Петя вошёл: ещё k − 1 из n, т.е. Cₙᵏ⁻¹. Не вошёл: k из n, т.е. Cₙᵏ. По правилу сложения — сумма.
  3. Подставим a = b = 1 в бином: 2ⁿ = Cₙ⁰ + … + Cₙⁿ. Или: обе части — число подмножеств n-элементного множества.

Формула включений-исключений

Т. «|A ∪ B| = |A| + |B| − |A ∩ B|; |A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|»

Примеры:

  1. Числа от 1 до 100, делящиеся на 2 или на 3: 50 + 33 − 16 = 67, т.к. на 6 делятся 16 чисел и они посчитаны дважды.

общую часть вычитаем, т.к. в |A| + |B| она посчитана два раза.
