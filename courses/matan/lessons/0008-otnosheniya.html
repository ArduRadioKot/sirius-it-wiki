Отношения и функции

Урок 7 · около 35 минут · билетные вопросы 5.1–5.4

Цель урока: знать, что такое бинарное отношение, его свойства (инъективность, сюръективность, функциональность, биективность), отношения эквивалентности и порядка, и доказать теорему о разбиении на классы.

Разминка

1. Бинарное отношение

Определение. Бинарным отношением между элементами множеств A и B называется любое подмножество R их декартова произведения A × B = {(a, b): a ∈ A, b ∈ B}. Вместо (x, y) ∈ R пишут x R y. Дехтярь и др., опр. 8

Пояснение

Отношение — это просто список пар «кто с кем связан». Например, на множестве {1, 2, 3} отношение «меньше» — это пары (1, 2), (1, 3), (2, 3).

Область определения dom R = {x: (x, y) ∈ R для некоторого y}, область значений rng R = {y: (x, y) ∈ R для некоторого x}.

Тождественное отношение на A: id_A = {(x, x): x ∈ A} — это диагональ декартова произведения A × A.

Композиция отношений R₁ ⊂ A × B и R₂ ⊂ B × C: R₁ ∘ R₂ = {(x, z): существует y, что (x, y) ∈ R₁ и (y, z) ∈ R₂}.

Пояснение

Композиция — «пройти два шага»: из x в y по первому отношению, из y в z по второму. «Мать» ∘ «мать» = «бабушка по матери».

Примеры из билета: дружба, «у окружностей общий центр», делимость, «мать — ребёнок».

2. Свойства отношений

Пусть R ⊂ A × B. Дехтярь и др., опр. 14–15

  • Функциональность: из (x, y₁) ∈ R и (x, y₂) ∈ R следует y₁ = y₂. Функциональное отношение с dom f = A называется функцией f: A → B.
  • Инъективность: из f(x₁) = f(x₂) следует x₁ = x₂.
  • Сюръективность: rng f = B.
  • Биективность (взаимная однозначность): инъективность и сюръективность одновременно.
Пояснение
  • Функциональность: из каждой точки выходит не больше одной стрелки.
  • Инъективность: в каждую точку приходит не больше одной стрелки (разные x дают разные y).
  • Сюръективность: в каждую точку B приходит хотя бы одна стрелка.
  • Биекция: каждой точке A ровно одна точка B и наоборот.

В разных книгах определения функциональности немного отличаются. На коллоквиуме используйте формулировки лектора.

3. Отношение эквивалентности

Определение. Бинарное отношение R на множестве A называется отношением эквивалентности, если оно рефлексивно (a R a для всех a), симметрично (из a R b следует b R a) и транзитивно (из a R b и b R c следует a R c). Дехтярь и др., опр. 10

Класс эквивалентности элемента a: [a] = {b ∈ A: a ~ b}.

Пояснение

Эквивалентность — «похожесть» по какому-то признаку. Пример: «одинаковый остаток при делении на 5». Классы — группы похожих: все числа с остатком 0, с остатком 1, … — всего 5 классов.

Теорема. Классы эквивалентности образуют разбиение множества A: каждый элемент лежит в некотором классе, и любые два класса либо совпадают, либо не пересекаются.

Доказательство. a ∈ [a] по рефлексивности. Пусть c ∈ [a] ∩ [b]. Тогда a ~ c и b ~ c; по симметричности c ~ b, по транзитивности a ~ b. Теперь любой x ∈ [b]: a ~ b, b ~ x ⇒ a ~ x, то есть [b] ⊂ [a]. Аналогично [a] ⊂ [b]. Значит, [a] = [b].

Обратное утверждение. Любое разбиение множества A задаёт отношение эквивалентности: a ~ b, если a и b лежат в одной части разбиения.

Пояснение: почему это эквивалентность

Рефлексивность: a лежит в своей части. Симметричность: «в одной части» не зависит от порядка. Транзитивность: если a и b в одной части, b и c в одной части, то это одна и та же часть (части не пересекаются), значит a и c в одной части.

4. Отношения порядка

Определение. Бинарное отношение R на A называется отношением частичного порядка, если оно антисимметрично (из a R b и b R a следует a = b) и транзитивно. Если R ещё и рефлексивно — порядок нестрогий, если антирефлексивно (a R a не выполняется ни для какого a) — строгий. Порядок называется линейным, если любые два элемента сравнимы. Дехтярь и др., опр. 12–13

Пояснение

≤ на числах — нестрогий линейный порядок (любые два числа сравнимы). Делимость на ℕ — частичный, но не линейный: 2 и 3 нельзя сравнить, ни одно не делит другое.

Отношения и функции

Опр. 1 «Бинарным отношением между элементами множеств A и B называется любое подмножество R их декартова произведения A × B»

Обозначение: (x, y) ∈ R или x R y. Декартово произведение: A × B = {(a, b): a ∈ A, b ∈ B}

Опр. 2 «Областью определения отношения R называется dom R = {x: (x, y) ∈ R для некоторого y}, областью значений — rng R = {y: (x, y) ∈ R для некоторого x}»

Опр. 3 «Тождественным отношением на множестве A называется отношение id_A = {(x, x): x ∈ A}. Это диагональ декартова произведения A × A»

Опр. 4 «Композицией отношений R₁ ⊂ A × B и R₂ ⊂ B × C называется отношение R₁ ∘ R₂ = {(x, z): существует y ∈ B такой, что (x, y) ∈ R₁ и (y, z) ∈ R₂}»

Примеры:

  1. «x дружит с y» на множестве людей.
  2. Делимость «x делит y» на ℕ.
  3. «Ребёнок → мать»: (x, y), где y — мать x.
  4. Композиция «мать матери» — это «бабушка по матери».

Свойства отношений

Опр. 5 «Отношение R ⊂ A × B называется функциональным, если из (x, y₁) ∈ R и (x, y₂) ∈ R следует y₁ = y₂»

Опр. 6 «Функциональное отношение f с dom f = A называется функцией из A в B»

Обозначение: f: A → B, f(x) = y

Опр. 7 «Функция f: A → B называется инъективной (разнозначной), если из f(x₁) = f(x₂) следует x₁ = x₂; сюръективной, если rng f = B; биективной (взаимно однозначной), если она инъективна и сюръективна»

Примеры:

  1. f(x) = 2x + 1, ℝ → ℝ — биекция, т.к. y = 2x + 1 однозначно решается: x = (y − 1)/2.
  2. f(x) = x², ℝ → ℝ — не инъективна, т.к. f(−1) = f(1); не сюръективна, т.к. −1 не значение.
  3. «Ребёнок → мать» — функция, но не инъективна, т.к. у братьев одна мать.
  4. Делимость на ℕ — не функциональна, т.к. 2 делит и 4, и 6.

в учебниках встречаются разные определения функциональности (иногда сразу требуют dom f = A). Сверьте с конспектом лектора.

Отношение эквивалентности

Опр. 8 «Бинарное отношение R на множестве A называется отношением эквивалентности, если оно 1) рефлексивно: (a, a) ∈ R для всех a; 2) симметрично: из (a, b) ∈ R следует (b, a) ∈ R; 3) транзитивно: из (a, b) ∈ R и (b, c) ∈ R следует (a, c) ∈ R»

Опр. 9 «Классом эквивалентности элемента a называется множество [a] = {b ∈ A: a ~ b}»

Примеры:

  1. Равенство остатков при делении на 5: 5 классов — по остаткам 0, 1, 2, 3, 4.
  2. «Окружности концентричны» (общий центр): класс — все окружности с данным центром.
  3. Дружба — не эквивалентность, т.к. не транзитивна.

Т. «Классы эквивалентности образуют разбиение множества A: каждый элемент лежит в некотором классе, а два класса либо совпадают, либо не пересекаются»

Доказательство: a ∈ [a] по рефлексивности. Пусть c ∈ [a] ∩ [b]: a ~ c, b ~ c, значит c ~ b (симметричность) и a ~ b (транзитивность). Тогда для x ∈ [b]: a ~ b, b ~ x ⇒ a ~ x, т.е. [b] ⊂ [a]; аналогично [a] ⊂ [b]. Значит, [a] = [b].

Т. (обратная) «Любое разбиение множества A задаёт отношение эквивалентности: a ~ b ⇔ a и b лежат в одной части разбиения»

Доказательство: рефлексивность: a в своей части; симметричность очевидна; транзитивность: если a, b в одной части и b, c в одной части, то это одна и та же часть (части не пересекаются), значит a, c в одной части.

Отношение порядка

Опр. 10 «Бинарное отношение R на A называется отношением частичного порядка, если оно антисимметрично (из (a, b) ∈ R и (b, a) ∈ R следует a = b) и транзитивно. Если R ещё и рефлексивно, порядок нестрогий; если антирефлексивно ((a, a) ∉ R), — строгий»

Опр. 11 «Частичный порядок называется линейным, если для любых a, b ∈ A верно (a, b) ∈ R, или (b, a) ∈ R, или a = b»

Примеры:

  1. ≤ на ℝ — нестрогий линейный порядок.
  2. < на ℝ — строгий линейный порядок.
  3. Делимость на ℕ — нестрогий частичный, но не линейный порядок, т.к. 2 и 3 не делят друг друга.
  4. ⊂ на множестве всех подмножеств — частичный порядок.
