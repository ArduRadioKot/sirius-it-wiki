Как писать ответ на билет

Памятка для письменной части коллоквиума

По правилам коллоквиума в письменном ответе нужно дать определения понятий из вопроса и сформулировать и доказать утверждения. Правила, п. 3

Одного примера мало. Скорее всего, за такой ответ больше ½ не поставят.

Ответ из 4 частей

  1. Определения. Выпишите из вопроса билета все термины. Под каждым напишите, что он значит.
  2. Формулировка. Само правило или теорема: словами или формулой.
  3. Доказательство. Почему это верно. Если в вопросе есть слова «теорема», «закон», «доказательство» или «свойство» — эта часть обязательна.
  4. Пример. Хотя бы один. Если можно — ещё и контрпример.

Первый шаг на коллоквиуме: подчеркните в билете все термины. Это и есть список определений, которые нужно написать.

Время: на 2 вопроса даётся 30–40 минут. Это примерно 15 минут на вопрос.

Пример: билет 1.4

Вопрос: «Кванторы общности (∀) и существования (∃). Высказывания, полученные связыванием переменных предиката с помощью кванторов. Построение отрицаний для высказываний и предикатов с кванторами».

Термины в вопросе: кванторы ∀ и ∃, предикат, высказывание, отрицание.

1. Определения

Высказывание — предложение, про которое можно сказать, истинно оно или ложно.

Предикат — предложение с переменной, которое становится высказыванием, если подставить значение переменной.

Кванторы. ∀x P(x) — «P(x) верно для всех x». ∃x: P(x) — «P(x) верно хотя бы для одного x».

Отрицание высказывания a — высказывание ¬a, которое истинно, когда a ложно, и наоборот.

2. Формулировка

¬(∀x P(x)) = ∃x: ¬P(x)

¬(∃x: P(x)) = ∀x ¬P(x)

Если кванторов несколько, меняем каждый ∀ на ∃ и каждый ∃ на ∀, порядок переменных не трогаем, условие заменяем на противоположное.

3. Доказательство

∀x P(x) ложно тогда и только тогда, когда P(x) ложно хотя бы для одного x, то есть когда ∃x: ¬P(x) истинно.

∃x: P(x) ложно тогда и только тогда, когда P(x) ложно для всех x, то есть когда ∀x ¬P(x) истинно.

4. Пример

¬(∀x ∈ ℝ ∃y ∈ ℝ: y > x) = ∃x ∈ ℝ ∀y ∈ ℝ: y ≤ x

Проверьте себя после ответа

  • Есть определение каждого термина из вопроса?
  • Есть формулировка?
  • Есть доказательство (если вопрос его требует)?
  • Есть пример?

Уроки: кванторы, теоремы. План: карта коллоквиума.
