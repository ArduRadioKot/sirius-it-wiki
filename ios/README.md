# Сириус Wiki для iPhone

Проект использует Capacitor 8 и общие материалы вики. Для сборки нужны Node.js 22, Xcode и CocoaPods. Из корня проекта выполните:

```sh
npm ci
npm run ios:sync
open ios/App/App.xcworkspace
```

В Xcode выберите схему **App**, симулятор iPhone и нажмите **Run**. Для запуска на своём iPhone укажите одну команду Apple для целей **App** и **SiriusWidgets** в **Signing & Capabilities**. У этой команды должна быть зарегистрирована группа `group.io.github.arduradiokot.siriuswiki`. Если используете свой идентификатор приложения, задайте дочерний идентификатор для расширения с суффиксом `.widgets` и свою зарегистрированную группу в параметре `SIRIUS_WIDGET_APP_GROUP` обеих целей.

Доступны встроенные статьи и учебники, автоматическая загрузка материалов для офлайн-чтения, расписание и ЛК. Вход в ЛК открывает официальный сайт Сириуса внутри отдельного окна. После входа приложение хранит последнюю копию данных на устройстве.

Чтобы добавить виджет, удерживайте пустое место на домашнем экране, выберите **Изменить → Добавить виджет** и найдите **Сириус Wiki**. Маленький виджет показывает ближайшую пару, средний — расписание на день, большой — расписание и кнопки **Пары**, **ЛК** и **Квизы**. Виджет использует группу из расписания приложения и последнюю сохранённую копию данных.

**До конца пары** показывает круговой отсчёт на домашнем экране и в круглом виджете экрана блокировки на iOS 16 и новее. **Осталось сегодня** показывает число оставшихся занятий и время окончания последней пары. Виджеты поддерживают системное стеклянное оформление iOS.

Чтобы настроить уведомления, откройте **Расписание**, прокрутите до строки **До конца пары**, выберите 3, 5 или 10 минут и нажмите **Напоминать**. Запланированные уведомления могут прийти при закрытом приложении. При обновлении расписания или смене группы ближайшие напоминания пересчитываются.

В **Расписании** также можно включить **Таймер на экране блокировки**. На iOS 16.2 и новее он показывает время до конца пары на экране блокировки и в Dynamic Island на совместимых iPhone. На iOS 26 приложение заранее планирует до пяти ближайших пар в пределах суток, пока позволяет системный лимит. iOS сопровождает запланированный запуск оповещением. На iOS 16.2–18 таймер запускается, когда приложение активно. После конца пары отсчёт останавливается. iOS может сохранить завершённую карточку, пока приложение свёрнуто. Выключение таймера убирает текущие и запланированные карточки.
