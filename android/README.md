# Сириус Wiki для Android

Сборка использует Capacitor 8, Node.js 22, JDK 21 или новее, Android SDK 36 и Build Tools 35.0.0.

Из корня проекта:

```sh
npm ci
npm run android:sync
cd android
./gradlew assembleDebug
```

Установочный файл появится в `android/app/build/outputs/apk/debug/app-debug.apk`. Это сборка для тестовой установки, подписанная отладочным ключом. Для публикации потребуется ключ выпуска.

В Android-приложении откройте **ЛК → Войти в ЛК**. Сириус открывает собственную страницу входа. После авторизации приложение загружает электронный журнал, учебную траекторию, новости и уведомления. Последняя копия хранится на устройстве. Кнопка **Отключить ЛК и удалить данные** стирает копию и сессию приложения.

Статьи, учебники и исходная копия расписания входят в APK. Приложение автоматически проверяет обновления материалов на GitHub Pages. Изменённые статьи, главы учебников, изображения и вложения сохраняются на устройстве. Если загрузка прерывается, остаётся доступна предыдущая полная копия. Внизу экрана **Обновить материалы и расписание** запускает синхронизацию вручную.
